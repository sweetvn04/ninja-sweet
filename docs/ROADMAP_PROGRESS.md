## 2. CÁC GIAI ĐOẠN PHÁT TRIỂN

### ⚪ GIAI ĐOẠN 1: KHỞI TẠO & MÔI TRƯỜNG RUNTIME
- [ ] Khởi động Database Ninja School (`nsoz`).
- [ ] Kiểm tra và biên dịch mã nguồn server Ninja School.
- [ ] Chạy thử nghiệm server trên Laptop PC và Android Termux.

### ⚪ GIAI ĐOẠN 2: CLIENT & KẾT NỐI MẠNG
- [ ] Cấu hình IP client kết nối tới Server.
- [ ] Kiểm tra đăng ký, đăng nhập và tạo nhân vật.

### ⚪ GIAI ĐOẠN 3: GAMEPLAY & NHIỆM VỤ
- [ ] Kiểm thử nhiệm vụ tân thủ (Làng Tone, Làng Kojin, Làng Sanzu...).
